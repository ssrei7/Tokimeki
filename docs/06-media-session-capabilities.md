# Media Session 能力边界

本项目只在浏览器暴露 `navigator.mediaSession` 时注册元数据和播放控制。所有操作仍由 App 壳层唯一的 `HTMLAudioElement` 执行；Media Session 不创建第二个播放器、不发起额外网络请求，也不用于后台保活。

| 环境 | 元数据与封面 | 播放 / 暂停 | 上一首 / 下一首 | 后台与系统界面边界 |
| --- | --- | --- | --- | --- |
| Chromium 桌面浏览器 | 通常可用 | 通常可用 | 取决于系统媒体面板 | 页面或浏览器被关闭后不可继续 |
| Android Chromium 浏览器 / PWA | 播放期间通常可进入通知栏或锁屏媒体卡片 | 通常可用 | 由浏览器和系统版本决定 | 系统省电、进程回收和外链断网仍会中断 |
| iOS Safari / 主屏幕 PWA | 支持程度随 iOS 与 WebKit 版本变化 | 播放活跃时可能可用 | 不保证系统一定展示 | 锁屏卡片、控制中心、耳机按键和灵动岛均不作承诺；冻结或回收后无法由网页恢复 |
| 未实现或部分实现 Media Session 的浏览器 | 静默跳过 | 继续使用应用内播放器 | 继续使用应用内播放器 | 不显示额外错误，不影响原有播放 |

## 代码侧验证

- API 不存在时不注册任何 handler，应用内播放器继续工作。
- 浏览器拒绝单个 action 时只跳过该 action，其余 action 继续注册。
- 曲目变化时更新标题、艺术家和本地 PWA 图标；无曲目时清除元数据。
- 播放状态同步为 `playing`、`paused` 或 `none`。
- 媒体时长有效时同步 position state；不支持或数据无效时静默跳过。

## 真机验证

Android 与 iOS 的浏览器、PWA 安装形态和系统媒体界面必须由用户在目标设备验证。验收结果只能描述实际测试设备、系统和浏览器版本，不能推广为所有移动设备都支持后台播放、锁屏控制或灵动岛展示。
