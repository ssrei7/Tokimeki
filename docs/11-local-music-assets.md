# 本地音乐资产

## 已实现范围

- 音乐 App 可由用户显式选择 MP3、M4A、AAC、OGG、WAV、WebM 或 FLAC 文件。
- 音频 Blob 保存到 Assets IndexedDB，曲目只保存 `stored AssetRef`；不会把 base64 或音频二进制写入世界存档。
- 本地曲目可离线播放，可修改标题和艺术家；不会自动读取、上传或重新请求原文件。
- 删除本地曲目前要求确认。只有最后一个音乐曲目引用被删除，且资产分类确认为 `music` 时，才回收对应二进制。
- 全局备份包含 MusicState 和全部本地音乐资产；通用资产完整性检查会把音乐曲目计入引用来源。

## 能力边界

- 文件扩展名和 MIME 类型通过校验，不代表当前浏览器或系统一定能解码；播放失败时保留曲目并显示错误。
- 本地查看、导入、播放、编辑、删除和引用审计均为零 Provider API。
- 世界 SaveFile 继续为 v41；音乐列表属于本机 Content IndexedDB，不随普通世界存档 JSON 导出。
- 现有外链曲目仍可直接播放。只有用户点击“缓存离线”时才下载，不会自动下载或在后台缓存。

## 外链离线缓存

- 缓存请求不携带 Cookie、Provider headers 或 API key。音频服务器必须允许浏览器跨域读取；否则仍可尝试浏览器直接播放，但无法保存离线副本。
- 缓存成功后曲目同时保留 URL 与本地 `AssetRef`，播放器优先使用本地资产；本地资产缺失时回退 URL。
- 单曲可移除缓存。数据管理可查看音乐资产数量、总字节数、本地导入数、外链缓存数、引用数和孤立资产数。
- “清理外链离线缓存”保留曲目和 URL；“清理无引用音乐资产”只删除无人引用的 `music` 二进制。本地导入音乐不会被批量缓存清理删除。
